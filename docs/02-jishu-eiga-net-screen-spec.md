# 自主映画ねっと 正式版 画面設計（実装記録）

Version 1.0 / 2026-08-10

## サービスの役割

「自主映画ねっと」は Project CINEVERSE において、世界中の自主映画を発見し、作品と監督を知るための映画メディアである。

映画との出会い方を次の二つで共存させる。

- **CINEVERSE TOWN**: 街を歩くように、偶然映画と出会う。
- **FILM DATABASE**: 国・ジャンル・監督名などから、目的の映画を探す。

## Phase 1 の公開ページ

| URL | 役割 |
| --- | --- |
| `/jishu-eiga-net/` | CINEVERSE TOWN、注目作品、国別導線、記事、広告枠 |
| `/jishu-eiga-net/films/` | フリーワード検索、国・ジャンル絞り込み、並び順 |

| `/jishu-eiga-net/interviews/[slug]/` | インタビュー記事 |
| `/jishu-eiga-net/about.html` | サービス方針・ポリシー公開予定 |
| `/jishu-eiga-net/contact.html` | 掲載・広告・問い合わせの窓口案内 |

## データと公開の方針

- 現在はバックエンド未接続のため、画面上で **デモデータ** と明示する。
- 作品数は固定の宣伝文句にせず、共通データ `assets/film-data.js` の公開件数から表示する。
- 映像は、制作者が許可した YouTube 公式プレイヤーのみを本番で埋め込む。独自サーバーへの転載はしない。
- AIは翻訳、要約、タグ提案を補助する。推測した事実を確定情報として掲載しない。
- 作品、監督プロフィール、インタビューは公開前に人が確認・承認する。
- 広告は「広告」または「SPONSORED」と明示し、作品と混同させない。

## アクセシビリティとスマートフォン

- ヘッダーは固定し、スマートフォンではハンバーガーメニューにする。
- アニメーション停止ボタンを常時利用可能にする。
- `prefers-reduced-motion` を尊重する。
- キーボードのフォーカス表示と、モーダルを閉じる操作を用意する。
- 小さな画面ではカードを1〜2列にし、街の演出より文字と操作の読みやすさを優先する。
